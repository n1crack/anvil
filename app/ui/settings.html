Performance

Microsoft Defender and other antivirus programs scan every file a program opens. Installing packages and starting a dev server read thousands of them, so the first start after a restart or an install can take a minute; later ones are quick.

Folders

On a Dev Drive, Defender scans without holding programs up. Anvil leaves these settings as they are, so you can choose what suits you.

Plugins

Off until you turn them on. One that is on gets its own page under Plugins.

Agents (MCP)

AI agents such as Claude Code see your apps, start and stop their processes and services, read logs and caught mail, add worktrees and change app settings.

Command for the agent’s MCP settingsClaude Code: claude mcp add anvil -- anvil mcp anvil mcp

Tunnel

Share an app at a temporary public address through a Cloudflare quick tunnel, no account needed.

SharingEach app’s Overview has Share; nothing is shared until you click it, and it stops when you stop it or quit Anvil.
